Amazon Gift Card Reviews · Three-Class Sentiment & Emotion

102 of 150 balanced reviews matched the star rating.

Sentiment is now three classes: positive (4–5★), neutral (3★), negative (1–2★). A model reads each review’s title and text only and picks one class, compared against the rating (used only as the correct answer, never shown to the model). Each review also gets a primary emotion from the model and from the NRC word-list. To stop the rare classes being swamped, the sample is balanced — 50 of each rating class — and picked with a fixed random seed.

Primary emotion · two independent methods

How often the model and the word-list agree

The model reads the review and names one emotion. The NRC word-list is a plain lookup table (NRC Emotion Lexicon) that counts emotion words in the review text and takes the highest category — no model call. Both answer: what is this review’s single primary emotion?

10.0%
The two methods chose the same primary emotion 15 of 150 times.
Agreement is low because the methods differ in kind. The model reads meaning; the word-list can be tipped by common words it scores as “anticipation” or “joy”. In 39 reviews the text held no NRC emotion words, so the word-list could not choose. Their category choices are compared below.

Method & caveats

Sample: 150 balanced reviews (50 per rating class) drawn from the whole file with a fixed random seed 2026; the same set is produced every run.

Sentiment: title + text only, never the rating. Rubric: 4–5 = positive, 3 = neutral, 1–2 = negative. Rating used only as the correct answer for scoring.

Primary emotion (model): one LLM call per review, Qwen3.6-35B, chain-of-thought disabled. Primary emotion (NRC): NRC-EmoLex v0.92 word-level; highest word-tally per category wins; ties broken by a fixed order; no model calls.

Neutral is the hardest class: 3-star reviews are often written with complaint-heavy text, so the model frequently reads them as negative.

Offline, no server or network required — everything is embedded in this single file.
